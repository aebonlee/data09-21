# data09-21 · 가족 기프티콘 관리

가족이 함께 기프티콘을 사진과 함께 등록하고, 유효기간 D-day·사용 여부·예약자를 한눈에 보며 「사용함」을 직접 체크하는 보관함

|---|---|

| 과정 | 현장 데이터 수집·디지털화 전문가과정 1차수 (2026) |
| 진행 단계 | 1단계 개발 완료 (2026-09-29) — https://aebonlee.github.io/data09-21/ |
| 다음 개발 | 2단계 — 카카오톡·문자 알림 발송(발송 대행 + 서버 예약 실행), 캡처 사진에서 상품명·유효기간 자동 읽기 |

## 실행 방법

**온라인에서 바로 보기: https://aebonlee.github.io/data09-21/**

처음 열면 **체험 모드**입니다. 예시 가족(엄마·아빠·첫째·둘째)과 기프티콘 8장이 들어 있고, 이 브라우저에만 저장됩니다. 사진은 가상 상호·가짜 바코드로 그린 예시 그림입니다.

**가족과 함께 쓰려면** 본인 Supabase 프로젝트를 만들고 [supabase/README.md](supabase/README.md) 순서대로 `supabase/schema.sql` 을 실행한 뒤, 앱 「설정」에 Project URL 과 anon 키를 넣습니다. 그다음 가족 각자 이메일로 가입하고, 한 사람이 가족을 만들어 **초대 코드**를 알려 줍니다. 주소·키는 그 브라우저에만 저장되며 이 저장소에는 어떤 키도 없습니다.

내 PC에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN 을 부르지 않습니다(Supabase 라이브러리는 `vendor/` 에 포함).

| 메뉴 | 하는 일 |
|---|---|
| 보관함 | 알림 띠(유효기간 임박), 요약 4칸 = 거르기 단추(사용 가능 · 7일 이내 만료 · 사용함 · 만료), 유효기간 빠른 순 카드(큰 D-day 배지 + 글자 풀이, 사진 썸네일 → 크게), 카드마다 「사용함」 체크·예약자·고치기·삭제 |
| 등록 | 캡처 사진 올리기(미리보기) + 상품명·발행처·유효기간·메모·예약자 |
| 기록 | 등록 · 수정 · 사용 · 사용취소 · 예약 · 삭제 — 한 사람·시각, 최근 순(고치거나 지울 수 없음) |
| 가족 | 초대 코드, 구성원, 내 표시 이름 (체험 모드: 「지금 쓰는 사람」 바꾸기) |
| 설정 | 알림 시점(기본 D-7·D-1), DB 연결, 체험 데이터 다시 채우기·지우기 |

- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- DB 스크립트 검증: `./scripts/sqltest/run.sh` (로컬 PostgreSQL 필요)

## 1단계 구현 범위

| 요청 | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 가족이 함께 등록·관리 | 완료 | 이메일 로그인, 가족 만들기·초대 코드, 같은 가족만 보기(RLS) |
| 사진으로 등록 | 완료 | 사진 올리기·비공개 저장·크게 보기. **사진에서 내용·유효기간 자동 읽기는 2단계** |
| 사용 여부 표시·삭제 | 완료 | 「사용함」 체크(누가·언제 기록, 되돌리기), 삭제 |
| 발행처 자동 사용 확인 | 하지 않음 | 공개 조회 경로가 없고 긁어오기는 약관·보안 위험 — 가족이 직접 체크(강사 결정) |
| 일정별 알림 | 대체 | 알림 시점 설정 + 앱 안 알림 띠. **카카오톡·문자 발송은 2단계**(유료 발송 대행·서버 필요) |
| 사용 예약 | 완료 | 가족 구성원 중 예약자 선택(DB 가 같은 가족만 허용) |
| 등록·사용 기록 | 완료 | DB 트리거가 덧붙이는 기록 표(고치기·지우기 불가) |
